# Разделение репозиториев — 2026-08-03

ChannelDesk разделён на два независимых репозитория, чтобы Bothost не определял
проект как Node.js и не пытался запускать Python через Node при каждом деплое.

## Текущая структура

| Репозиторий | Содержимое | Хостинг |
|---|---|---|
| `rportnazkin7-hash/channeldesk` | **только Python-бот** (`bot/`, `migrations/`, `migrate.py`, `docs/`, `tests/test_bot.py`) — НЕТ `package.json` | **Bothost** (Python Worker) |
| `rportnazkin7-hash/channeldesk-web` | frontend (`src/`) + FastAPI (`api/`) + `vercel.json` + tests | **Vercel** → https://channeldesk.vercel.app |

## Почему

В корне `channeldesk` лежал `package.json` (фронтенд), и Bothost автоматически
определял проект как Node.js → `ERR_UNKNOWN_FILE_EXTENSION .py`.
Теперь фронтенд живёт отдельно, а репозиторий бота — чистый Python.

## Правила дальше

- Пушить фронтенд/API → в `channeldesk-web`. Это **не** перезапускает бота.
- Пушить бота/миграции → в `channeldesk`. Это не трогает Vercel.
- Общая БД Supabase одна; миграции дублируются в обоих репозиториях
  (`channeldesk-web` хранит копию для справки, применяет её владелец вручную).

## Bothost (после разделения)

Проверить настройки:

```text
Runtime: Python
Type: Worker
Python: 3.11
Entry point: bot/main.py
Requirements: requirements.txt
```

После любого изменения — полный **Rebuild** (не restart). Токен бота
и DATABASE_URL в Bothost менять не нужно.
