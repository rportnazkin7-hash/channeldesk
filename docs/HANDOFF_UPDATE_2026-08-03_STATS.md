# Handoff: статистика и финансы — 2026-08-03

## Версия

Web: `v0.24.0`. Фича добавлена поверх web `cc6c70d` и bot `81fbf28`.

## Что сделано

- В Mini App добавлен экран **Статистика** в разделе «Ещё».
- Реализованы доход, расход, прибыль и количество операций за выбранный месяц.
- Добавлен график динамики за последние 6 месяцев.
- Добавлен список транзакций с рекламодателем и каналом, если операция привязана к брони.
- Добавлено ручное создание дохода/расхода с категорией, датой и комментарием.
- Экспорт CSV/XLSX/PDF теперь можно запросить за выбранный месяц.
- PDF-экспорт бота исправлен: финансовый PDF больше не маскируется под список публикаций.
- Миграция `014_finance_export_period.sql` добавляет период к заданиям экспорта. Она присутствует в обоих репозиториях и применяется автоматически.
- Миграция `015_media_kit_exports.sql` разрешает тип `media_kits` в очереди экспорта.
- В разделе «Ещё → Медиакиты» добавлена кнопка отправки PDF в Telegram.
- Бот собирает PDF медиакитов с каналом, описанием, статистикой, ценами и контактами.
- Миграция `016_channel_analytics.sql` добавляет дневные метрики каналов и собственные ссылки.
- В Mini App добавлен экран «Ещё → Аналитика каналов»: период, фильтр канала, охват, просмотры, подписчики, ручные метрики, клики и конверсии.
- Для аналитики добавлены RBAC-действия `analytics.view` и `analytics.manage`.
- Добавлен собственный MTProto-сборщик для подключённых каналов: `bot/mtproto_analytics.py`, синхронизация раз в 6 часов, хранение подробных Telegram-снимков.
- Для запуска нужны секреты Bothost: `MT_PROTO_API_ID`, `MT_PROTO_API_HASH`, `MT_PROTO_SESSION_STRING`; генератор сессии — `bot/create_mtproto_session.py`.
- В интерфейсе добавлен блок «Статистика Telegram» с подписчиками, просмотрами/пост, репостами/пост и реакциями/пост.
- Денежные входные значения API переведены с `float` на `Decimal`; SQL продолжает хранить суммы в `numeric`.

## После деплоя

1. Проверить `/api/health` — версия должна быть `0.24.0`.
2. Проверить применение миграций `014`–`017`.
3. Добавить на Bothost секреты `MT_PROTO_API_ID`, `MT_PROTO_API_HASH`, `MT_PROTO_SESSION_STRING` и сделать редеплой бота.
4. Обновить версию WebView в BotFather и Bothost (`?v=N`), чтобы Telegram не показывал старый кэш.
5. Открыть «Ещё → Статистика», выбрать месяц и проверить экспорт PDF/XLSX.
6. Открыть «Ещё → Медиакиты» и проверить отправку PDF в Telegram.
7. Открыть «Ещё → Аналитика каналов», добавить дневную метрику и проверить блок «Статистика Telegram».
